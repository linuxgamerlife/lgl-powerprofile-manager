# Archived Qt implementation

This directory contains the historical Qt 6 implementation of LGL Power Profile
Manager. It is retained only as migration reference. It is not built, tested,
packaged, or eligible for new feature work.

- `src/` - the Qt `MainWindow`, application entry point, and profile data
- `resources/` - the Qt resource file and the original master artwork
- `docs/` - the Qt-era README and setup instructions
- `lgl-powerprofile-manager.desktop` - the Qt-era desktop entry
- `CMakeLists.txt` - the Qt-era build description

The maintained GTK application is built from the repository root.
